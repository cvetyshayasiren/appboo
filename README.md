# appboo

1. "Открыть" = "Перейти", "В iframe" = "Окно"
2. Клик по карточке должен сразу открывать мини-приложение
3. Пройдись по всем мини-приложениям и измени иконки, приведи к общему виду, минимализм
4. Фильтр по нейросетям
5. Нажатие на тег или нейросеть, должны сразу применять фильтр только с этим тегом/нейросетью
6. Поменяй цвет темы, базовый цвет "#86C26B"
7. Порядок в apps.json соответсвует времени появления, новые в конце списка. Сортировка "default" должна показывать новые сверху (от новых к старым)
