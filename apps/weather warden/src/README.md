# ПОГОДНЫЙ СТРАЖ / Weather Warden

Пиксель-арт веб-игра про управление погодой над маленьким островом.
Чистый HTML + CSS + JavaScript, **без внешних зависимостей, библиотек и ассетов** — вся графика
рисуется кодом на `<canvas>` с внутренним разрешением 320×176 и масштабируется в целое число
раз (nearest-neighbour), поэтому пиксели остаются чёткими.

## Запуск

```bash
# вариант 1 — открыть index.html двойным кликом
# вариант 2 — локальный сервер
python3 -m http.server 8080
# затем http://localhost:8080
```

Файл `weather-warden.html` — автономная сборка со встроенными CSS и JS, работает офлайн из одного файла.

## Управление

| Клавиша | Действие |
|---|---|
| `1` | Ясно — бесплатно, сушит почву, поднимает настроение |
| `2` | Дождь — 10 магии, поливает грядки |
| `3` | Гроза — 20 магии, ливень и молнии |
| `4` | Снег — 12 магии, холод; в тепле тает в воду |
| `5` | Туман — 8 магии, молнии в тумане дают ×2 магии |
| `6` | Ветер — 6 магии, рассеивает туман и облака, сушит почву |
| `Space` | Пауза |
| `R` | Начать заново |
| `M` | Звук вкл/выкл |
| ЛКМ по грядке | собрать урожай (когда созрела) |
| ЛКМ по облаку с разрядом | поймать молнию |
| ЛКМ по жителю | поговорить с жителем |

## Правила

Вы — хранитель погоды. Цель: **дожить до конца 6-го дня и собрать 5 урожаев**, не уронив настроение
жителей до нуля.

Симуляция тянет 6 связанных величин:

- **Магия** — валюта для переключения погоды. Копится сама (+1…+2.6/сек, больше в дождь), плюс за урожай и пойманные молнии.
- **Температура** — ищет баланс: сезон (весна → лето → осень → зима) + время суток + эффект погоды. Комфортно при 14…26 °C.
- **Влажность почвы** — растёт в дождь/грозу, падает в жару и на ветру. Ниже 12 % — засуха и недовольство.
- **Настроение** — сумма погоды, комфорта температуры и состояния полей. Упало в ноль — жители уходят.
- **Грядки** — 5 грядок на ферме; урожай зреет только при влажной почве и комфортной температуре.
- **Молнии** — в грозе в облаке появляется разряд: успей кликнуть (2.8 сек), иначе он ударит в дерево или дом.

Тонкости: туман прячет всё, но в нём молнии вдвое прибыльнее; ветер выдувает туман; снег в тепле
тает в воду; гроза может сжечь дерево или разрушить дом, и это бьёт по настроению.

## Структура

```
weather-warden/
├── index.html   — разметка, HUD, оверлеи
├── style.css    — ретро-UI
├── game.js      — весь движок: мир, погода, симуляция, рендер, звук
└── README.md
```

Звук синтезируется на лету через Web Audio API (без файлов). Остров генерируется процедурно
(value-noise + эллипс), поэтому каждая партия — новый остров.

Проверено в Chromium: консольных ошибок нет, сценарий «поймать молнию → собрать урожай → дожить
до 6-го дня → победа» и сценарий «настроение в ноль → поражение» отрабатывают корректно,
вёрстка адаптирована под мобильные экраны.
