Искусство по открытым артериям музеев

Art Arter даёт доступ к музеям через их открытые API — без ключей и регистрации. Список музеев может пополняться в будущем, если будут найдены другие открытые API. Каждый объект показывается только при явном подтверждении прав: принцип «Только 100% допустимое».

Главное правило

Только 100% допустимое

Объект появляется на экране, только если все его части — метаданные и изображение — абсолютно точно разрешены к показу. При малейшем сомнении объект пропускается. Никаких предположений «наверное, можно».

01

Явное поле прав

API должно вернуть машиночитаемое подтверждение: флаг общественного достояния. Нет флага — нет показа.

Прозрачность

Как работают запросы

Каждый музей — отдельный адаптер: свой поиск, своя пагинация, свои лимиты вежливости и своё поле подтверждения прав. Ответы кэшируются в localStorage, чтобы не дёргать API повторно.

The Met

collectionapi.metmuseum.org
ЗапросыGET /public/collection/v1.1/search → GET /objects/{id}
СхемаПоиск возвращает страницы ID (offset/limit, hasImages=true). Каждый объект загружается отдельно и проверяется по флагу.
ПроверкаisPublicDomain === true + primaryImageSmall
ЛимитыЛимит музея — 80 запросов/с; приложение держит ≤ 5 параллельных и паузу 80 мс.
ПраваДанные и PD-изображения — CC0 (Open Access). Атрибуция: creditLine.

Art Institute of Chicago

api.artic.edu
ЗапросыGET /api/v1/artworks/search?params={JSON}
СхемаElasticsearch-запрос: term is_public_domain=true + exists image_id. Одна страница — до 36 записей со всеми полями; изображения строятся по IIIF.
Проверкаis_public_domain === true + image_id
ЛимитыАнонимно — 60 запросов/мин; приложение делает не чаще 1 запроса в 1,15 с. Глубина поиска ограничена API.
ПраваМетаданные — CC0 (кроме поля description, CC-BY); PD-изображения — по флагу музея. Атрибуция: credit_line.

Whitney Museum

whitney.org/api
ЗапросыGET /api/artworks?q[…]&page=N
СхемаJSON:API, 30 записей на страницу, поиск через q[title_cont] и т. п. Записи читаются, но ни одна не допускается к показу.
ПроверкаЯвного поля прав на изображение в ответе нет → отказ по правилу «Только 100% допустимое».
ЛимитыПросьба музея «be respectful»: 1 запрос в 1,2 с, без параллельных обращений.
ПраваДанные — для некоммерческого образовательного использования с атрибуцией; изображения не входят в открытые данные (CC0 — только CSV-датасеты).

Ни один объект не допущен к показу

API Уитни работает и отдаёт метаданные: их условия разрешают некоммерческое образовательное использование с сохранением уведомлений об авторских правах и указанием источника. Но в ответах нет явного машиночитаемого поля, подтверждающего право на показ изображений.

Правило «Только 100% допустимое» запрещает показ при малейшем сомнении — поэтому коллекция здесь не отображается. Это не ошибка: это работа фильтра. Ниже — живой журнал проверки записей, полученных из API прямо сейчас.

Если Уитни добавит в API явное поле прав (например, public_domain: true), объекты пройдут фильтр и появятся здесь автоматически — код адаптера уже проверяет такие поля. Список музеев проекта может пополняться, когда находятся другие открытые API.
