Источники энтропии

Выберите, откуда собирать случайность. У каждого источника — оценочная криптостойкость с пояснением. Подготовка каждого источника начинается сразу при добавлении. На Mix остаётся только смешивание готовых данных.

Данные источников подготавливаются сразу при добавлении карточки. Базовый CSPRNG нельзя удалить, но можно выключить. Данные обрабатываются локально, кроме явно обозначенных сетевых источников.

Смешивание энтропии

Источники уже подготовлены на вкладке Source. Здесь настройте цепочку шагов и смешайте сохранённые байты в пул. Итоговая оценка — эвристическая.

Пайплайн смешивания

    Форматы вывода

    Числа, сиды, выбор из списка, текст по алфавиту, кубики, UUID и даты. Можно добавлять несколько карточек одного типа с разными параметрами.
